# Kiểm thử

Giữ tests/test_member1.py hiện có. unit/: logic độc lập; integration/: API/DB/WS/module; load/: kịch bản tải; fixtures/: dữ liệu giả lập dùng chung. Chạy từ gốc bằng .venv/Scripts/python.exe -m pytest -q. Không thêm test giả luôn pass hoặc thông báo chức năng hoàn thành khi mới có file khung.
