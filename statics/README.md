# Sơ đồ và dữ liệu mẫu

Các file `architecture`, `protocol`, `network_p95` và `judge_throughput` được tạo bởi `scripts/build_report.py`. Biểu đồ đọc số đo có nguồn gốc trong `experiments/results`; không nhập số minh họa thay cho kết quả đo.

`datasets/students.csv` là dữ liệu sinh viên giả lập để thử import CSV, cùng mẫu mà frontend cung cấp. Không chứa danh sách lớp thật. Preview để kiểm tra nội dung trước khi confirm; không dùng trên DB thật nếu chưa xem lại.
